# Preview genre collections

Compare current Audiobookshelf genres with existing collections per library and show create, update, in-sync, empty, name-taken or delete-on-apply outcomes, with how many books the ticked collections hold. Specific genres and the main non-fiction subjects start ticked; Non-Fiction itself is listed with the subgenres.
