# Benchmark

Comparing matching tools on the same real audiobooks: the dataset of books in their original state, every
tool's run over them, the audit of every result, and the public comparison page built from that audit.

## Boundary

Does not own matching itself: LibraForge's own matching is Metadata Forge's, and the benchmark runs it as one
of the tools. Does not write anything to the library it reads its books from.
